# Enclosure Files

Use the three `.3mf` plates to print the enclosure. The `.stl` files contain the same six parts separately.

Before printing, use the [Hardware](../docs/hardware-parts.md) guide to gather the electronics and assembly supplies. For printer settings and assembly instructions, see [Print and Assemble the Enclosure](../docs/hardware.md).

Import `claude-design.html` into Claude Design if you need to change the model and export new files, or open it directly in Chrome.
